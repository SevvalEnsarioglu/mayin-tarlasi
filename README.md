# 💣 Mayın Tarlası (Minesweeper)

React ve TypeScript kullanılarak geliştirilmiş klasik Mayın Tarlası oyunu.

## Özellikler
- Dinamik ızgara boyutu seçimi
- İlk tık asla mayın değil
- Recursive hücre açılımı
- Sağ tık ile bayrak koyma / kaldırma
- Kronometre
- Kazanma ve kaybetme durumları

## Teknolojiler
- React
- TypeScript
- Vite

## Çalıştırma
```bash
npm install
npm run dev
